# Сайт РИС-Дизайн

Лендинг компании **РИС-Дизайн** — дизайн интерьеров, ремонт, комплектация и изготовление мебели в Самаре.

**Сайт:** https://whyisomi.github.io/ris-design/

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: интро-экран, калькулятор заявки (5 вопросов), услуги, о компании, как мы работаем, отзывы, контакты, карта |
| `portfolio.html` | Портфолио: 4 дизайн-проекта, 106 3D-визуализаций по комнатам |

## Портфолио

Альбом открывается кликом по карточке проекта:

- вкладки по комнатам (названия как на Яндекс Диске);
- сетка миниатюр → клик открывает полноразмерное фото;
- просмотрщик: стрелки, счётчик, клавиши `←` `→` `Esc`, свайп на телефоне;
- CTA «Хочу такой проект» ведёт на форму заявки.

Секция «Реализованные проекты» — заглушка, будет наполнена после съёмки объектов.

## Структура

```
media/
  logo.webp, photo1-5.webp, отзыв1-3.webp
  portfolio/
    manifest.js                       ← список проектов (window.RIS_PORTFOLIO)
    <project-slug>/
      cover.webp
      <room-slug>/
        01.webp          полное фото, 1400px
        01.thumb.webp    превью, 420px
tools/
  fetch_disk.py    скачать фото с Яндекс Диска
  optimize.py      пересобрать WebP и манифест
  serve.py         локальный сервер
```

Манифест — обычный JS-файл, а не JSON, поэтому сайт работает и с `file://`, и на хостинге.

## Обновление портфолио

1. Загрузить фото на Яндекс Диск, разложить по папкам `ЖК ... / Комната /`.
2. Скопировать новую публичную ссылку в `tools/fetch_disk.py` (`SHARE`).
3. Скачать оригиналы:

   ```bash
   RIS_ORIGINALS=/home/iso/rissite-originals python3 tools/fetch_disk.py
   ```

4. Пересобрать WebP и манифест:

   ```bash
   python3 tools/optimize.py
   ```

5. Закоммитить и запушить — GitHub Actions задеплоит сам.

## Локальный запуск

```bash
python3 tools/serve.py . 8080
# http://127.0.0.1:8080
```

## Оптимизация

Вся графика — WebP. Сайт весит **~12 МБ** вместо ~135 МБ в исходниках.

Оригиналы хранятся вне репозитория (в `media/_originals/` на рабочей машине) и на деплой не попадают.

## Деплой

`.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages при пуше в `main`.
