# Сайт РИС-Дизайн

Лендинг компании **РИС-Дизайн** — дизайн интерьеров, ремонт, комплектация и изготовление мебели в Самаре.

**Сайт:** https://whyisomi.github.io/ris-design/

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: интро-экран, калькулятор заявки (5 вопросов), услуги, о компании, как мы работаем, отзывы, контакты, карта |
| `portfolio.html` | Портфолио: 4 дизайн-проекта + 5 реализованных объектов, 330 фото по альбомам |

## Приветствие (заставка)

Удалено: сайт открывается сразу с основного экрана. Прежняя кинематографичная
заставка (фото с зумом, логотип, домен, телефон, автоскрытие через 2.2 с)
полностью убрана из `index.html` — вместе со стилями, разметкой и скриптом.
Файл `media/intro.webp` больше не используется на страницах.

## Портфолио

Альбом открывается кликом по карточке проекта:

- вкладки по комнатам (названия как на Яндекс Диске);
- сетка миниатюр → клик открывает полноразмерное фото;
- просмотрщик: стрелки, счётчик, клавиши `←` `→` `Esc`, свайп на телефоне;
- CTA «Хочу такой проект» ведёт на форму заявки.

**Дизайн-проекты** — 3D-визуализации (источник: Яндекс Диск, `Дизайн-проект (2)`).

**Реализованные проекты** — реальные объекты после ремонта (источник: Telegram).
Сборка: `/home/iso/tg-tools/build_realized.py`, разметка комнат — `rooms_realized.json`.
Альбом «Другие помещения» объединяет чаты «Другие кухни / спальни / санузлы / прочие».

## Структура

```
media/
  logo.webp, photo1-5.webp, отзыв1-3.webp
  portfolio/
    manifest.js                       ← список проектов (window.RIS_PORTFOLIO)
    <design-slug>/                   ← дизайн-проекты
      cover.webp
      <room-slug>/
        01.webp          полное фото, 1400px
        01.thumb.webp    превью, 420px
    realized/                        ← реализованные объекты
      <object-slug>/
        cover.webp
        <room-slug>/...
tools/
  optimize.py        пересобрать WebP и манифест
  media_utils.py     общие утилиты конвертации
```

Манифест — обычный JS-файл, а не JSON, поэтому сайт работает и с `file://`, и на хостинге.

## Обновление портфолио

1. Загрузить фото на Яндекс Диск, разложить по папкам `ЖК ... / Комната /`.
2. Скопировать новую публичную ссылку в `tools/fetch_disk.py` (`SHARE`).
3. Скачать оригиналы:

   ```bash
   RIS_ORIGINALS=/home/iso/rissite-originals python3 tools/fetch_disk.py
   ```

4. Пересобрать WebP и манифест:

   ```bash
   python3 tools/optimize.py
   ```

5. Закоммитить и запушить — GitHub Actions задеплоит сам.

## Локальный запуск

```bash
python3 /home/iso/tg-tools/serve.py . 8080
# http://127.0.0.1:8080
```

## Оптимизация

Вся графика — WebP. Сайт весит **~30 МБ** вместо ~390 МБ в исходниках
(фото проектов 130 МБ + 200 фото из Telegram 31 МБ).

Оригиналы хранятся вне репозитория (`/home/iso/rissite-originals/`,
`/home/iso/tg-raw/`) и на деплой не попадают.

## Деплой
